## you will need
- plate (3d printed is fine)
- 27 mx switches
- keycaps (product page no longer exists, but I used xda profile pbt keycaps from amazon. they should all sound about the same)
- a 2u cherry plate mount stabilizer
- a keyboard controller
- double sided tape
- cardboard
- the patience to handwire and program everything

## build notes
kle data can be found [here](https://www.keyboard-layout-editor.com/#/gists/2c89043110a27b35943a61478b9f9195).

joe scotto has some good videos on how to [handwire a keyboard](https://youtu.be/hjml-K-pV4E).
